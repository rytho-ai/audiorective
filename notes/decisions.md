| 2   | Microphone hand-wired 5/6; desire invents input + monitoring + permission errors + `Symbol.dispose`                                 | `MicrophoneInput.open(context, { audio?, signal? }): Promise<MicrophoneInput>` (AudioProcessor: `output`, `connect`, `dispose`/`[Symbol.dispose]`), `stream`, `cells.state` (`"live" \| "ended"`), writable `cells.monitoring` (routes to `context.destination`). | 3   | R1 100% hand-computed bar boundary; with context 3/3 attach recorder to Clock                                                       | `AudioRecorder` is a Clock `Scheduler` (`clock.attach(recorder)`). `record({ when?, quantize?, length?, signal? }): Promise<RecordedAudio>`; `quantize` `"none" \| "<n>m" \| "<n>n"` (same as launcher), `length` seconds or note value (`"4m"`). `RecordedAudio.startBeat: number \| null`. `cells.startsAt` / `cells.startedAt` (audio-context seconds, launcher naming). `stop({ when? })` ends early and settles the same promise.
